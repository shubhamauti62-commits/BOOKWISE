# Bookwise

A mobile-first personal book learning app: **read less, remember more**.

V1 validates a focused flow: Library → Book overview → Chapter → Learn → Recall.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## V1
- Personal library UI
- Book overview and chapter navigation
- Memory-friendly chapter cards
- Real-world examples and one-line memory anchors
- Active-recall interaction
- Local progress state

Prototype content is an original educational summary inspired by concepts discussed in *Thinking, Fast and Slow*; it does not reproduce book text.
